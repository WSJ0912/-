# 医生工作流评价协议

覆盖 `RELEASE_GATES.md` 的 **W-04**（约 50 个任务）与 **W-05**（只评价术语与工作流）。

> **W-05 是本次评价最重要的约束**
> 本次评价**只评价软件术语、阅片操作、复核流程和报告流程的可用性**。
> **不评价诊断准确率，不评价热力图的医学合理性，不构成任何临床有效性结论。**
> 报告中不得出现"准确""灵敏""漏诊率"等性能表述；被评价的模型也**不是医疗器械**。

## 1. 目的

确认专业人员能否在不被误导的前提下，顺畅完成
"导入 → 阅片 → 复核 → 出报告" 这条工作流，并收集**术语是否清楚**的反馈。

不回答的问题：模型准不准、热力图指的对不对、能不能用于临床。
