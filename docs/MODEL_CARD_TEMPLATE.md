# 模型卡模板

用于满足 `RELEASE_GATES.md` 的 **R-05**（最终模型卡）。模板中的 `<...>` 必须在
首次正式运行产出真实结果后，用**实测值**替换，并同时记录执行人与日期。

> **填写红线**
> - 不得用合成数据、冒烟试跑或未训练模型的数值填入本卡。
> - 不得写入诊断准确率、临床有效性或任何监管结论。本项目不是医疗器械。
> - 任何未测量的字段保持 `--`，不得估算、不得留空当作 0。
> - 本卡必须与 `.medmodel` 中的 `manifest.json`、`docs/RELEASE_GATES.md` 的
>   R-01 ~ R-05 记录三方一致；冲突时以 `.medmodel` 内哈希为准。

## 2. 预期用途与明确不适用场景

| 项目 | 内容 |
| --- | --- |
| 预期用途 | 成人正位 AP/PA 胸片的多标签**筛查辅助**，输出 14 项观察的概率，供专业人员复核 |
| 目标使用者 | 经过培训的放射科／临床专业人员 |
| 明确不适用 | 儿科、侧位片、非胸片、CT/MRI/超声等其他模态、独立诊断、任何自动化决策 |
| 定位声明 | 科研与竞赛原型，**不是医疗器械**，不构成诊断结论 |

- 训练集为单一公开数据集，跨机构、跨设备、跨人群的泛化性**未验证**。
- 未做儿科、侧位、非胸片场景验证；这些输入应在导入阶段被拒绝。
- 热力图的**医学合理性未评估**；CAM 只表示模型关注区域，不是病灶定位。
